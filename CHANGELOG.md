# Changelog

## v0.5 — Modern UI refresh
- Modern glassmorphism HUD and refined typography.
- Responsive resource, objective, command and event panels.
- Improved button hover/focus/touch states.
- Refined intro modal, toast notifications and mobile joystick visuals.
- Added reduced-motion support.

## v0.4 — Kingdoms: Full Gameplay Foundation
- Added castles, troop classes, unit orders, economy, buildings, outpost capture, rival reinforcements and local save/load.

## v0.3 — Castles & Armies
- Added medieval castles, recruitable soldiers, gold HUD and arcade siege prototype.

## v0.2 — 3D Foundation
- Added Three.js world, third-person camera, commander and four helpers.


## v0.9 — World Map & Rival AI
- Added nine strategic regions across the frontier.
- Added neutral territory claims for gold and resource rewards.
- Added periodic rival AI expansion into neutral regions.
- Added responsive strategic map overlay and ownership status.


## v1.0 — Command & Army battlefield direction
- Added Rush, Attack, Follow and Hold squad command controls.
- Added line, block and wedge formation presets.
- Added procedural mounted commander horse and mount/dismount control.
- Added squad status card and mobile action HUD.
- Added heal, sprint and roll action prototypes.


## v1.1 — Ultimate Command Campaign (development preview)
- Added a unified Kingdom Command panel with Army, Realm, Trade, Diplomacy, Campaign and World tabs.
- Added spearmen, cavalry and royal guard recruitment with differentiated stats and procedural troop accessories.
- Added trade exchanges, worker hiring, watchtower construction and kingdom overview.
- Added four campaign objectives and achievement unlock notifications.
- Added river crossing, bridge, rolling terrain and animated village residents.
- Added clear/rain/fog visual presets, day/night lighting and campaign season progression labels.
- Extended local save metadata for campaign, workers, trades and formation.
- Preserved the previous third-person battlefield, recruitment, economy, outpost capture, world map, horse toggle, commands and landscape HUD.
