# Changelog

## v0.3 — Castles & Armies
- Added player and rival medieval castle structures with towers, keeps, walls and flags.
- Added gold resource and soldier recruitment.
- Added army HUD and an arcade siege command.
- Added visual castle damage by hiding wall sections as abstract fort health decreases.
- Kept the existing Three.js world, camera and mobile controls.

## v0.2 — 3D Foundation
- Three.js 3D world, third-person camera, commander and four helpers.
- Basic outposts, score, timer and rival movement.
- Mobile joystick and desktop keyboard controls.
